# 🏢 نظام إدارة الموارد البشرية H-HR

نظام إدارة موارد بشرية احترافي وكامل مع واجهة عربية سهلة الاستخدام. يشمل إدارة الموظفين، الحضور والانصراف، الرواتب، الإجازات، والمهام.

---

## ✨ المميزات الرئيسية

- ✅ **إدارة الموظفين**: إضافة وتعديل وتعطيل/تفعيل الموظفين
- ✅ **نظام الحضور والانصراف**: مع التحقق من الموقع GPS ورقم الجهاز
- ✅ **الجداول الأسبوعية**: توزيع الشيفتات على الموظفين
- ✅ **إدارة المهام**: إسناد ومتابعة المهام اليومية والأسبوعية
- ✅ **إدارة الإجازات**: طلب وموافقة على الإجازات مع حساب الرصيد
- ✅ **المرتبات**: حساب المرتبات مع السلف والخصومات والوقت الإضافي
- ✅ **الجزاءات**: تسجيل المخالفات وحسابها تلقائياً
- ✅ **التنبيهات الأمنية**: مراقبة محاولات الدخول والأجهزة المسجلة
- ✅ **سجل العمليات**: تسجيل جميع الإجراءات الإدارية
- ✅ **لوحة القيادة**: إحصائيات وملخصات فوري للعمليات

---

## 📋 المتطلبات

### قبل البدء تأكد من توفر:

- **Node.js**: الإصدار 14.0.0 أو أحدث
- **npm** أو **yarn**: مدير الحزم
- **PostgreSQL**: قاعدة البيانات (إصدار 12+)
  - محلي: أو من خدمة سحابية مثل Neon أو Railway

## 🚀 التثبيت والإعداد

### 1️⃣ استنساخ المشروع

```bash
git clone https://github.com/your-repo/h-hr.git
cd h-hr
```

### 2️⃣ تثبيت المتطلبات

```bash
npm install
```

### 3️⃣ إعداد متغيرات البيئة

نسخ الملف `.env.example` إلى `.env` وتعديل البيانات:

```bash
cp .env.example .env
```

**محتوى `.env`:**

```env
NODE_ENV=production
PORT=3000

# قاعدة البيانات
DATABASE_URL=postgresql://user:password@host:5432/h-hr-db

# الدول المسموحة
ALLOWED_ORIGINS=http://localhost:3000,https://yourdomain.com

# إعدادات افتراضية
DEFAULT_COMPANY_NAME=Mura
DEFAULT_ADMIN_USERNAME=admin
DEFAULT_ADMIN_PASSWORD=Admin@123
```

#### خيارات قاعدة البيانات:

**أ) محلي (MySQL/PostgreSQL):**
```
postgresql://postgres:password@localhost:5432/h-hr-db
```

**ب) Neon (مجاني - 0.5$ شهري):**
```
postgresql://user:password@ep-xxxx.us-east-1.aws.neon.tech/h-hr-db?sslmode=require
```

**ج) Railway (سهل جداً):**
```
postgresql://user:password@containers-us-west-xxx.railway.app:xxxx/railway
```

**د) Heroku PostgreSQL:**
```
postgresql://user:password@ec2-xxx.compute-1.amazonaws.com:5432/database
```

### 4️⃣ إعداد قاعدة البيانات

```bash
npm run setup-db
```

هذا الأمر سيقوم بـ:
- ✅ إنشاء جميع الجداول
- ✅ إنشاء مسؤول افتراضي
- ✅ إدراج الإعدادات الأولية

## 🐛 استكشاف الأخطاء

### خطأ الاتصال بقاعدة البيانات:

```
❌ فشل الاتصال بـ PostgreSQL
```

**الحل:**
- ✅ تحقق من `DATABASE_URL` في `.env`
- ✅ تأكد من أن قاعدة البيانات قيد التشغيل
- ✅ اختبر الاتصال: `psql $DATABASE_URL`

### الخطأ: "جداول غير موجودة"

**الحل:**
```bash
npm run setup-db
```

### خطأ في الوصول (401 Unauthorized):

- ✅ تحقق من بيانات تسجيل الدخول
- ✅ تأكد من أن الحساب نشط
- ✅ امسح cache المتصفح

## 🆘 الأسئلة الشائعة

**س: كيف أقوم بتغيير اسم الشركة؟**
- من الإدارة → الإعدادات → اسم الشركة

**س: هل يمكن استخدام قاعدة بيانات MySQL؟**
- للأسف لا، النظام مصمم لـ PostgreSQL فقط

**س: كم عدد الموظفين الذين يمكن إدارتهم؟**
- بدون حد أقصى، لكن يُنصح بـ 500-1000 موظف أقصى على سرفر واحد

**س: هل هناك نسخة محمولة؟**
- جاري العمل على تطبيق جوال (iOS/Android)

**س: كيف أقوم بالنسخ الاحتياطي؟**
```bash
pg_dump $DATABASE_URL > backup.sql
```
